## 🔐 第二步：连接到服务器

### Windows 用户

**方式 1：使用 PuTTY（推荐新手）**

1. 下载 PuTTY: https://www.putty.org/
2. 打开 PuTTY
3. 填写信息：
   - Host Name: `你的服务器IP`
   - Port: `22`
   - Connection type: `SSH`
4. 点击 "Open"
5. 首次连接会提示信任密钥，点 "是"
6. 输入用户名 `root`
7. 输入密码（不显示，直接输入后回车）

**方式 2：使用 Windows Terminal（推荐）**

```powershell
# 打开 PowerShell 或 Windows Terminal
ssh root@你的服务器IP

# 输入密码
```

### macOS / Linux 用户

```bash
# 打开终端
ssh root@你的服务器IP

# 首次连接输入 yes
# 然后输入密码
```

**成功连接后会看到类似这样的提示**：
```
Welcome to Ubuntu 22.04 LTS
root@vultr:~#
```

## 📦 第三步：上传部署文件

### 方法一：使用 Git（推荐，最简单）

在服务器上执行：

```bash
# 1. 安装 git（如果没有）
apt update && apt install -y git          # Ubuntu/Debian
# 或
yum install -y git                        # CentOS

# 2. 克隆你的项目
git clone https://github.com/你的用户名/test.git

# 3. 进入目录
cd test/13_SSR/selfbuild
```

### 方法二：手动上传文件

**Windows 用户 - 使用 WinSCP**：

1. 下载 WinSCP: https://winscp.net/
2. 新建连接：
   - 文件协议: `SFTP`
   - 主机名: `你的服务器IP`
   - 端口: `22`
   - 用户名: `root`
   - 密码: `你的密码`
3. 登录后，将本地的 `13_SSR/selfbuild/` 文件夹拖拽到服务器 `/root/` 目录

**macOS / Linux 用户 - 使用 scp**：

```bash
# 在本地电脑执行
cd /path/to/your/test
scp -r 13_SSR/selfbuild root@你的服务器IP:/root/

# 输入密码后等待上传完成
```

## 🚀 第四步：运行部署脚本

### 方案 A：一键部署（推荐新手）

在服务器上执行：

```bash
# 1. 进入部署目录
cd /root/selfbuild    # 如果是手动上传
# 或
cd /root/test/13_SSR/selfbuild    # 如果是 git clone

# 2. 添加执行权限
chmod +x deploy.sh

# 3. 运行一键部署脚本
bash deploy.sh
```

**脚本会自动完成**：
1. 检查并安装 Docker
2. 构建 SSR 镜像（需要 3-5 分钟）
3. 启动管理脚本

### 方案 B：分步部署（推荐高级用户）

```bash
# 步骤 1: 构建镜像
cd /root/selfbuild
chmod +x build-docker.sh
bash build-docker.sh

# 等待构建完成（3-5 分钟）

# 步骤 2: 运行管理脚本
chmod +x ssr-plus.sh
bash ssr-plus.sh
```

### 首次安装步骤

**1. 输入 `1` 安装 SSR**

```bash
请输入端口 [默认20000]: 8388          # 建议改成其他端口
请输入密码 [默认dongtaiwang.com]: MySecurePassword123  # 设置强密码
```

**2. 选择加密方式**

```
请选择加密方式:
 1) none
 ...

输入序号 [默认16]: 16    # 直接回车，使用推荐的
```

**3. 选择协议**

```
请选择协议 (protocol):
 1) origin
 2) auth_sha1_v4
 ...
输入序号 [默认2]: 2    # 直接回车
```

**4. 选择混淆**

```
请选择混淆 (obfs):
 1) plain
 2) http_simple
 ...
输入序号 [默认1]: 1    # 直接回车
```

**5. 等待安装完成**

安装成功后会显示：
```

===== 当前 SSR 配置 =====
🌐 IPv4     : xxx.xxx.xxx.xxx

🔑 密码     : MySecurePassword123

**重要**：复制并保存这个 `ssr://` 开头的链接！

```

## 🔥 第六步：配置防火墙

### 云服务商安全组（重要！）

大部分云服务商需要在**控制台**开放端口：

**Vultr / DigitalOcean / Linode**：
1. 登录控制台
2. 找到你的服务器
3. 进入 "Firewall" 或 "安全组"
4. 添加入站规则：
   - 协议: `TCP`
   - 端口: `8388`（你设置的端口）
   - 来源: `0.0.0.0/0`（所有IP）

**AWS Lightsail**：
1. 进入实例详情
2. 点击 "Networking" 标签
3. 添加规则：
   - Application: `Custom`
   - Protocol: `TCP`
   - Port: `8388`

### 服务器防火墙

**Ubuntu/Debian (UFW)**：
```bash
# 开放端口
ufw allow 8388/tcp

# 启用防火墙
ufw enable

# 检查状态
ufw status
```

**CentOS/RHEL (firewalld)**：
```bash
# 开放端口
firewall-cmd --permanent --add-port=8388/tcp

# 重载防火墙
firewall-cmd --reload

# 检查状态
firewall-cmd --list-all
```

## 🛠️ 常见问题处理

### 问题 1：无法连接

**检查清单**：
```bash
# 1. 检查 SSR 是否运行
docker ps | grep ssr

# 2. 检查端口是否开放
netstat -tlnp | grep 8388

# 3. 检查防火墙
ufw status                    # Ubuntu/Debian
firewall-cmd --list-all       # CentOS
```

**解决方案**：
- 确保云服务商安全组已开放端口
- 检查端口号是否正确
- 重启 SSR: `bash ssr-plus.sh` → 选择 `6`

### 问题 2：速度慢

**优化建议**：
```bash
# 1. 启用 BBR 加速
bash ssr-plus.sh
# 选择 8) 启用系统加速

# 2. 尝试更换加密方式
bash ssr-plus.sh
# 选择 2) 修改配置
# 选择更快的加密: chacha20-ietf
```

### 问题 3：镜像构建失败

**原因**：网络问题导致 git clone 超时

**解决方案**：
```bash
# 设置 Git 代理（如果本地有代理）
git config --global http.proxy http://代理地址:端口

# 或使用国内镜像
# 编辑 Dockerfile，替换 GitHub 地址
```

## 🔒 安全建议

1. **使用强密码**：至少 16 位，包含大小写字母+数字+符号
2. **修改 SSH 端口**：
   ```bash
   # 编辑 SSH 配置
   nano /etc/ssh/sshd_config
   # 修改 Port 22 为其他端口（如 2222）
   # 重启 SSH
   systemctl restart sshd
   ```
3. **禁用密码登录，使用 SSH 密钥**
4. **定期更新系统**：
   ```bash
   apt update && apt upgrade -y    # Ubuntu/Debian
   yum update -y                   # CentOS
   ```
5. **定期更改 SSR 密码和端口**
