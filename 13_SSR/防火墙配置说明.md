# 防火墙配置说明

## 为什么原始脚本可能需要手动配置防火墙？

### 情况一：UFW 已启用（需要配置）

**部分 Vultr/云服务器的 Ubuntu 系统**：
- UFW 可能是**已启用**状态（active）
- 可以通过 `ufw status` 查看：
  ```
  Status: active

  To                         Action      From
  --                         ------      ----
  22/tcp                     ALLOW       Anywhere
  ```
- 此时**只有明确允许的端口才能访问**
- SSR 端口默认被阻拦，**客户端无法连接**

### 情况二：UFW 未启用（不需要配置）

**某些云服务器的 Ubuntu/Debian 系统**：
- UFW 默认状态：**未启用**（inactive）
- 可以通过 `ufw status` 查看，显示：
  ```
  Status: inactive
  ```
- 当 UFW 未启用时，所有端口默认都是开放的

**CentOS/RHEL 系统**：
- firewalld 在某些云服务器镜像中也是**未启用**的
- 或者配置为默认放行大部分流量

### 原因二：Vultr 的云防火墙（安全组）配置

Vultr 有两层防火墙：

1. **服务器本地防火墙**（UFW/firewalld/iptables）
   - 大多数情况下默认未启用
   - 不会阻拦任何流量

2. **Vultr 云防火墙**（在控制台配置）
   - 这是**可选功能**，不是默认启用的
   - 如果你没有在 Vultr 控制台创建并应用防火墙规则，所有端口都是开放的

### 验证你的服务器状态

在你的 Vultr 服务器上运行：

```bash
# 检查 UFW 状态
sudo ufw status

# 结果 1: Status: inactive
# 说明防火墙未启用，所有端口都开放，原始脚本可以正常工作

# 结果 2: Status: active
# 说明防火墙已启用，只有允许的端口才能访问
# 必须配置防火墙才能让 SSR 工作！
```

登录 Vultr 控制台：
- 点击你的服务器
- 查看 "Firewall" 选项卡
- 如果显示 "No firewall group applied"，说明没有云防火墙规则

## 什么时候需要配置防火墙？

### 需要配置的场景

1. **UFW 已启用**（常见情况）
   ```bash
   ufw status
   # 显示: Status: active
   ```
   - Vultr 等云服务商的某些镜像默认启用了 UFW
   - 启用后，**只有明确允许的端口才能访问**
   - **SSR 端口默认被阻拦，客户端无法连接**

2. **使用了 Vultr 云防火墙**
   - 在控制台创建了防火墙组并应用到服务器

3. **某些安全加固的镜像**
   - 预装了并启用了防火墙

4. **企业环境或安全要求高的场景**
   - 主动配置防火墙提高安全性

### 不需要配置的场景

- ✅ UFW 未启用（Status: inactive）
- ✅ 未使用 Vultr 云防火墙
- ✅ 所有端口默认开放

## 建议

### 对于 UFW 已启用的情况（如你的 Vultr 服务器）

**推荐：使用我的自建脚本**
- ✅ **自动检测 UFW 已启用**
- ✅ **自动配置 SSR 端口**
- ✅ **无需手动操作**
- ✅ **修改端口时自动更新防火墙规则**

只需运行一键安装：
```bash
wget -O install.sh https://raw.githubusercontent.com/basteng/test/main/13_SSR/selfbuild/install.sh && chmod +x install.sh && bash install.sh
```

**手动配置方式**（如果使用原始脚本）
```bash
# 1. 安装 SSR 后，手动允许 SSR 端口
ufw allow 8388/tcp
ufw allow 8388/udp

# 2. 查看状态
ufw status numbered
```

### 对于 UFW 未启用的情况

**选项 1：保持现状**
- 继续不启用防火墙
- SSR 可以正常工作
- 依赖 SSH 密钥和强密码保护

**选项 2：启用防火墙（更安全，推荐）**
```bash
# 1. 允许 SSH（重要！避免锁死自己）
ufw allow 22/tcp

# 2. 允许 SSR 端口
ufw allow 8388/tcp
ufw allow 8388/udp

# 3. 启用防火墙
ufw enable

# 4. 查看状态
ufw status
```

### 使用我的自建脚本的优势

如果你启用了 UFW，我的脚本会自动：
1. ✅ 检测防火墙状态
2. ✅ 自动开放 SSR 端口
3. ✅ 询问是否启用 UFW
4. ✅ 避免手动配置的麻烦
