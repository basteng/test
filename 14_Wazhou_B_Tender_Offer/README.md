# 14_Wazhou_B_Tender_Offer — 瓦轴B要约收购跟踪

## 项目简介

跟踪瓦轴B（股票代码：200706）2024年12月由控股股东瓦房店轴承集团有限责任公司发起的全面要约收购进展。要约价格 **2.86港元/股**，目的是终止公司上市地位（私有化退市）。

---

## 文件结构

```
14_Wazhou_B_Tender_Offer/
├── README.md                          # 本文件：项目说明与修改日志
├── generate_tender_progress_chart.py  # 生成要约收购进展趋势图
├── generate_price_vs_shares_chart.py  # 生成股价与预受股份对比图
├── generate_volume_turnover_chart.py  # 生成交易量和换手率分析图
└── reports/
    ├── 瓦轴B要约收购信息汇总.md          # 主分析报告（每日数据+深度分析）
    ├── investment_strategy_insights.md  # 投资策略与收益分析（汇率/金额测算）
    ├── tender_offer_progress_chart.png  # 要约收购进展图
    ├── stock_price_vs_shares_chart.png  # 股价走势与完成率对比图
    └── volume_turnover_chart.png        # 交易活跃度分析图
```

---

## 快速使用

更新数据后，在项目目录下运行以下命令重新生成图表：

```bash
cd 14_Wazhou_B_Tender_Offer
python3 generate_tender_progress_chart.py
python3 generate_price_vs_shares_chart.py
python3 generate_volume_turnover_chart.py
```

依赖：`pip3 install matplotlib`
