## 问题二：汇率波动对收益的影响

### 💱 汇率敏感性分析

**交易涉及的汇率**：
- B股以港币计价和交易
- 如果您的本金是人民币，需考虑两次汇率转换：
  1. 人民币 → 港币（买入时）
  2. 港币 → 人民币（卖出时）

**当前汇率参考**（2026年1月）：
- 港币兑人民币汇率：约0.92（即1港元≈0.92人民币）
- 该汇率随市场波动，近期波动范围：0.90-0.94

### 📈 不同汇率情景下的收益影响

假设投资10万人民币，买入价2.78港元，卖出价2.86港元：

#### 情景一：汇率不变（最理想）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.92人民币

购买力：100,000 / 0.92 = 108,695港元
买入股数：108,695 / 2.78 = 39,098股
卖出收入：39,098 × 2.86 = 111,820港元
人民币收入：111,820 × 0.92 = 102,874元
净收益：102,874 - 100,000 = 2,874元
收益率：2.87%
```

#### 情景二：港币升值（负面影响）

港币升值意味着汇率下降（如从0.92降至0.90）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.90人民币（港币升值）

购买力：100,000 / 0.92 = 108,695港元
买入股数：39,098股
卖出收入：111,820港元
人民币收入：111,820 × 0.90 = 100,638元
净收益：100,638 - 100,000 = 638元
收益率：0.64% ⚠️ 大幅缩水！
```

#### 情景三：港币贬值（正面影响）

港币贬值意味着汇率上升（如从0.92升至0.94）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.94人民币（港币贬值）

购买力：100,000 / 0.92 = 108,695港元
买入股数：39,098股
卖出收入：111,820港元
人民币收入：111,820 × 0.94 = 105,111元
净收益：105,111 - 100,000 = 5,111元
收益率：5.11% 🎉 收益增强！
```

### 🎲 汇率风险总结

| 汇率变动 | 对收益影响 | 概率评估 | 风险等级 |
|---------|-----------|---------|---------|
| 港币升值2% | 收益减少约2% | 中等 | ⚠️⚠️⚠️ |
| 汇率稳定 | 收益约2.88% | 较低 | ⚠️⚠️ |
| 港币贬值2% | 收益增加约2% | 中等 | ✅ |

**关键结论**：
- 汇率波动可能**完全吞噬**2.88%的套利收益
- 持有期30-60天，汇率风险不可忽视
- 港币相对人民币的走势不确定性增加投资风险
