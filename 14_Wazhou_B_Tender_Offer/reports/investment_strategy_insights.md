## 问题二：汇率波动对收益的影响

### 💱 汇率敏感性分析（2026年2月更新）

**交易涉及的汇率**：
- B股以港币计价和交易
- 如果您的本金是人民币，需考虑两次汇率转换：
  1. 人民币 → 港币（买入时）
  2. 港币 → 人民币（卖出时）

**当前汇率参考**（2026年2月）：
- 港币兑人民币汇率：约0.91-0.93（即1港元≈0.92人民币）
- 近期波动范围：0.90-0.94

### 📈 不同汇率情景下的收益影响

假设投资10万人民币，买入价2.810港元，卖出价2.86港元：

#### 情景一：汇率不变（基准情景）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.92人民币

购买力：100,000 / 0.92 = 108,695港元
买入股数：108,695 / 2.810 = 38,684股
卖出收入：38,684 × 2.86 = 110,636港元
人民币收入：110,636 × 0.92 = 101,785元
净收益：101,785 - 100,000 = 1,785元
收益率：1.79%
```

扣除交易成本（0.7%）后：
```
实际净收益：约1,000元
实际收益率：约1.0%
```

#### 情景二：港币升值2%（不利）

港币升值意味着汇率下降（如从0.92降至0.90）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.90人民币（港币升值）

购买力：100,000 / 0.92 = 108,695港元
买入股数：38,684股
卖出收入：110,636港元
人民币收入：110,636 × 0.90 = 99,572元
净收益：99,572 - 100,000 = -428元
收益率：-0.43% ⚠️ 亏损！
```

**关键**：汇率不利变动**可能完全吞噬套利收益甚至导致亏损**

#### 情景三：港币贬值2%（有利）

港币贬值意味着汇率上升（如从0.92升至0.94）

```
买入时汇率：1港元 = 0.92人民币
卖出时汇率：1港元 = 0.94人民币（港币贬值）

购买力：100,000 / 0.92 = 108,695港元
买入股数：38,684股
卖出收入：110,636港元
人民币收入：110,636 × 0.94 = 103,998元
净收益：103,998 - 100,000 = 3,998元
收益率：4.0% 🎉
```

### 🎲 汇率风险总结

| 汇率变动 | 对10万投资的影响 | 概率评估 | 风险等级 |
|---------|----------------|---------|---------|
| 港币升值2% | 可能亏损400元 | 中等 | ⚠️⚠️⚠️ |
| 汇率稳定 | 盈利约1,000元 | 中等 | ⚠️⚠️ |
| 港币贬值2% | 盈利约4,000元 | 中等 | ✅ |

**关键结论**：
- 套利空间仅1.78%，**汇率2%波动可能完全吞噬收益甚至导致亏损**
- 持有期30-90天，汇率风险不可忽视
- 考虑汇率风险后，期望收益更低
