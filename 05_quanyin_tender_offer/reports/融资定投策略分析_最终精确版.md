## 💡 为什么差异这么小？

### 1. 融资总额差异小

```
每天差额 = 10,000 - (股数 × 开盘价)
        = 10,000 - 9,999.xx
        ≈ 0-10元

18天累计差额 = 87.13元
占比 = 87.13 / 180,000 = 0.048%
```

### 2. 股数取整是向下的

```
12-08：10,000 / 11.52 = 868.06 → 868股
实际金额：868 × 11.52 = 9,999.36元
差额：0.64元

每天差额都很小，累计也不大
```

### 3. 利息差异更小

```
利息 = 融资额 × 8.35% × (天数/365)

融资额差异：0.048%
利息差异：0.048% × 8.35% × (平均天数/365)
        ≈ 0.01-0.03%

完全可以忽略
```
