# 定投策略验证：每日买入+12月31日卖出

## 策略描述

**核心思路**：
- 不参与要约收购（不预受）
- 从12月8日开始，每个交易日等额买入
- 在12月31日（要约最后一天之前）全部卖出
- 利用要约收购期间的股价上涨趋势获利

### 收益计算

```
总股数：15,704股
平均成本：180,000 / 15,704 = 11.462元/股

12月31日卖出：
- 卖出价：11.68元/股
- 卖出总额：15,704 × 11.68 = 183,423元

毛收益：183,423 - 180,000 = 3,423元
毛收益率：3,423 / 180,000 = 1.90%

持有时间：23天（从12-08到12-31）
年化收益率：1.90% × (365/23) ≈ 30.2%
```

### 考虑交易成本

**假设交易成本**：
- 买入佣金：0.025%（18次买入）
- 卖出佣金：0.025%（1次卖出）
- 卖出印花税：0.1%（仅卖出时收取）

```
买入成本 = 180,000 × 0.025% × 18 = 810元
卖出佣金 = 183,423 × 0.025% = 46元
印花税 = 183,423 × 0.1% = 183元
总成本 = 810 + 46 + 183 = 1,039元

净收益 = 3,423 - 1,039 = 2,384元
净收益率 = 2,384 / 180,000 = 1.32%
年化收益率 ≈ 1.32% × (365/23) ≈ 21.0%
```

## 策略评估

### ✅ 优点

1. **完全避开要约收购风险**
   - 不预受要约，不会遭遇超额认购
   - 不会遭遇要约结束后的跌停
   - 风险完全可控

2. **利用上涨趋势**
   - 要约收购期间，股价从11.50涨到11.68（+1.57%）
   - 定投策略平滑了买入成本（11.462元）
   - 在接近高点时退出（12-31: 11.68元）

3. **时机把握准确**
   - 12-31完成度66%，已经很高但还未疯狂
   - 避开了1月5日的不确定性
   - 如果继续持有到1月5日，可能卖在11.69，但风险激增

4. **年化收益可观**
   - 净年化收益约21%（考虑交易成本）
   - 风险远低于参与要约收购

### ⚠️ 风险和问题

1. **时机判断难度**
   - 如何知道12-31是退出的好时机？
   - 如果12月中旬股价下跌怎么办？
   - 需要实时监控完成度和股价关系

2. **股价可能下跌**
   - 假设股价从11.50跌到11.30：
   - 平均成本11.462，卖出11.30
   - 亏损：(11.30-11.462) × 15,704 = -2,544元
   - 亏损率：-1.41%

3. **交易成本侵蚀利润**
   - 18次买入的累计佣金较高
   - 如果改为每周买入，可降低成本

4. **资金分批投入的机会成本**
   - 前17天的资金未完全使用
   - 如果一次性买入可能收益更高（但风险也更高）

### 🔄 策略优化建议

**改进版1：分3批买入**
```
第1批（12-08到12-12，5天）：投入60,000元
第2批（12-22到12-26，5天）：投入60,000元
第3批（12-29到12-31，3天）：投入60,000元
12-31全部卖出
```
- 优点：降低交易成本，简化操作
- 缺点：失去定投平滑成本的优势

**改进版2：根据完成度动态调整**
```
完成度<50%：积极买入（每天15,000元）
完成度50-60%：谨慎买入（每天10,000元）
完成度>60%：停止买入，准备退出
完成度>65% 或 12-31：全部卖出
```
- 优点：更灵活，风险更小
- 缺点：需要每日监控，决策复杂
