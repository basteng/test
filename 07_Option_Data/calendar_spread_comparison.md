## 💡 策略原理解析

### 为什么50ETF适合正向价差？

**市场特征**：
- 流动性极好，波动率稳定
- 近月期权时间价值衰减慢且均匀
- 远月期权保持较高时间价值

**盈利原理**：
```
建仓：卖近月100元 + 买远月150元 = 支出50元
到期：近月归零 + 远月剩余100元 = 回收100元
盈利：100 - 50 = 50元 ✅
```

### 为什么500ETF适合反向价差？

**市场特征**：
- 波动率高，弹性大
- 波动率骤变时，价差快速收敛
- 临期效应明显（距到期7天效应最强）

**盈利原理**：
```
建仓：买近月100元 + 卖远月150元 = 收入50元
距到期7天：
  - 近月快速升值（或远月快速贬值）
  - 价差收敛，平仓盈利
预期盈利：~1680点 ✅
```

## ⚠️ 风险提示

### 50ETF正向价差风险

1. **波动率暴涨风险**：如果近月波动率突然上升，可能亏损
2. **时间成本**：需要持有较长时间，资金占用
3. **极端行情**：遇到单边大涨或大跌，可能提前止损

### 500ETF反向价差风险

1. **择时风险**：必须在距到期7天平仓，否则大幅回撤
2. **波动风险**：持仓期间可能经历大幅浮动盈亏
3. **亏损案例**：8个样本中有3个亏损（距到期7天时）
