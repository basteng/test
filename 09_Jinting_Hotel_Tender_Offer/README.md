# 君庭酒店要约收购信息

## 项目简介

本文件夹用于搜集和整理君庭酒店（股票代码：301073）被湖北文化旅游集团有限公司要约收购的相关信息。

**交易概要**：
- 收购方：湖北文化旅游集团有限公司（湖北文旅）
- 标的：君亭酒店集团股份有限公司36%股权
- 交易金额：约18亿元（协议转让14.99亿元 + 要约收购约3亿元）
- 交易价格：25.71元/股
- 公告日期：2025年12月2日

## 核心要点

1. **控制权转移**：交易完成后，君亭酒店控股股东变更为湖北文旅，实际控制人变更为湖北省国资委

2. **交易结构**：协议转让29.99% + 部分要约收购6.01% + 原控股股东放弃10%表决权 = 实际控制46%表决权

3. **未来规划**：湖北文旅拟注入优质住宿业资产，并提供融资增信支持

4. **行业意义**：2025年国资密集入场酒店业的典型案例
